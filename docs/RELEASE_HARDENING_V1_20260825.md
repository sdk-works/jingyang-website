# 京阳温室官网安全与稳定性完善版

日期：2026-08-25  
分支：`hardening-v1`

## 已完成

- 后端端口统一为 4001，前端统一通过同域 `/api` 访问。
- CORS 改为环境变量白名单，官网部署目录独立为 `/var/www/jingyang-website`。
- 移除 JWT 默认密钥；未配置密钥时拒绝认证服务。
- 登录、咨询和计算器接口增加限流，启用 Helmet 安全响应头和请求体大小限制。
- 补齐服务端 RBAC：viewer 只读、editor 可维护内容、admin 可管理咨询和价格、superadmin 管理账号。
- 上传扩展名与 MIME 严格对应；服务器根据 MIME 生成安全扩展名。
- 咨询写库失败返回 503，不再虚假提示成功；邮件内容统一 HTML 转义。
- 公开系统设置改为固定白名单。
- 分页、面积、价格、账号角色和长度增加边界校验。
- 初始化和密码重置脚本不再使用或打印默认密码。
- 多语言统一使用 `next-i18next` 和 Next.js locale 路由，移除浏览器端免费翻译接口。
- 导航栏完成四语言切换，新增阿拉伯语 RTL 和移动端菜单。
- 产品、案例和新闻由后端返回目标语言，缺失翻译时回退中文。
- 修复产品/案例接口字段与前端字段不一致导致图片和描述不显示的问题。

## 部署前必须完成

1. 修改当前默认管理员密码，至少 12 位且不得与数据库密码相同。
2. 在 `backend/.env` 设置长度至少 32 位的随机 `JWT_SECRET`。
3. 设置正式 `CORS_ORIGIN`、数据库密码和 SMTP 参数。
4. 使用独立官网域名和 `/var/www/jingyang-website`，禁止覆盖智慧大棚云端目录。
5. 对中、英、俄、阿内容进行人工校对；缺失动态翻译时系统会显示中文，而不是调用不稳定的在线翻译。

## 兼容说明

- API 路径保持不变。
- 后台入口仍为 `/manage888`。
- JWT 密钥改变后，旧登录 Token 自动失效。
- 自动翻译已移除，后台应逐步补齐产品、案例、文章的多语言字段。
