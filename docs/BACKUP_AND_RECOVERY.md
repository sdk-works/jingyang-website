# 备份与恢复

需要同时保留四类资料：Git源码/版本、PostgreSQL数据备份、后台uploads、运行环境配置。

- 源码：GitHub私有仓库与本地Git bundle保留独立副本。
- 数据库：使用数据库原生备份工具，由运行环境管理员保存至受控备份位置；不提交Git。
- 上传文件：与数据库备份记录相应时间点，避免只恢复记录而缺少文件。
- 运行配置：数据库凭据、JWT、SMTP及服务配置独立加密保管，不写进Issue或PR。

恢复时先在隔离环境恢复同一代码版本、数据库和uploads，配置环境变量，验证登录、内容、询盘与图片，再考虑切换站点。不要用仓库里的schema或初始化脚本直接覆盖已有生产库。

本次GitHub迁移没有执行新的数据库/媒体备份，也未开展整站恢复演练；历史发布备份仍需单独管理。
