# 预算计算器配置说明

后台“系统设置 → 计算器设备与系统管理”用于维护前台预算计算器选项。

- `温室`：基础类型，前台单选。
- `系统`：配套设备或系统，前台多选并叠加单价。
- 每项均可新增、查看、修改名称和单价、调整排序、启用或停用、删除。
- 停用后前台不再展示，但数据仍保留，适合临时下架；删除用于确定不再使用的项目。
- 单价单位为元/㎡，前台总价为“面积 ×（基础单价 + 已选配套系统单价）”。

数据保存在 PostgreSQL 的 `calculator_items` 表。部署或迁移服务器时执行 `database/migrate_all.sql`；现有服务器可执行 `database/migrate_calculator_items.sql`。
