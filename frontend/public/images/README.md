# 图片素材放置说明

## 目录结构
```
/public/images/
├── home/
│   └── hero-bg.jpg          ← 首页 Hero 大背景图（建议 1920×1080）
├── about/
│   ├── company.jpg          ← 公司外观照片（建议 800×600）
│   └── factory.jpg          ← 工厂车间图（建议 800×600）
├── products/
│   ├── wenlo-glass.jpg      ← 文洛型玻璃温室
│   ├── pc-panel.jpg         ← 阳光板温室（PC板）
│   ├── solar-room.jpg       ← 日光温室
│   ├── film-multispan.jpg   ← 薄膜连栋温室
│   ├── single-arch.jpg      ← 单体拱棚
│   ├── cooling-sys.jpg      ← 降温系统
│   ├── heating-sys.jpg      ← 升温系统
│   ├── irrigation-sys.jpg   ← 喷灌系统
│   ├── lighting-sys.jpg     ← 补光系统
│   ├── seedbed-sys.jpg      ← 苗床系统
│   ├── core-parts.jpg       ← 核心配件
│   ├── struct-parts.jpg     ← 配套材料
│   └── heat-drive-parts.jpg ← 供暖配件
├── cases/
│   ├── shandong-sunrise-seed.jpg   ← 山东旭日种业案例
│   ├── shaanxi-qianxian-veggie.jpg ← 陕西乾县案例
│   ├── liaocheng-zhengxin.jpg      ← 聊城正信味业案例
│   ├── liaocheng-ruitai.jpg        ← 聊城瑞泰案例
│   └── henan-youlin.jpg            ← 河南佑林案例
└── news/
    └── {article-slug}.jpg          ← 新闻文章封面图
```

## 使用规范
- 格式：JPG（照片）或 PNG（带透明度）
- 产品/案例图尺寸建议：800×600 或 16:9
- 所有图片由运营人员自行上传到对应目录
- 代码中已用注释标注每处图片路径，搜索 `/images/` 可快速定位
